# 設計方針

## 少し手強く、でも旅は終わらない

おんぼろカーで山や草原を走り、景色と不思議な出来事を楽しむドライブアクションです。目指すのは、初めてでも先へ進め、慣れるほど滑らかに速く走れること。時計は締め切りではなく、自分の上達を確かめる目安です。

後方視点で、自然のラリー風景と開放感を重視します。おんぼろカーは相棒としての設定であり、操作をわざと不安定にはしていません。画面・車体の振動も加えていません。

## 現在の遊び

### 道を読む

左右のカーブ、上り、頂上、下りを持つ8区間の道がループします。林間や岩場の囲まれた区間と、草原・谷・湖の開けた区間を対比させています。遠い雲や雪山と、画面端を通り抜ける巨木・断崖の動きで奥行きと速度差を表現します。

基本操作はハンドル・アクセル・ブレーキだけ。路肩へ大きくはみ出すと穏やかに減速しますが、反対へハンドルを切れば道路へ戻れます。

### 一般車を追い越す

同方向へゆっくり走る一般車に追いつき、空いている側から抜きます。v0.4では急な車線変更や対向車はありません。接触しても短く減速するだけで、横転や長い停止、最初からのやり直しは発生しません。

### UFOの光線を避ける

牧草地では、牛がふわっと浮く接近演出から、道路の予告、光線照射、退場へ進みます。牛が傷つく表現はありません。

| 状態 | ゲームフレーム数 | 遊びの役割 |
| --- | ---: | --- |
| 接近 | 30 | UFOと浮かぶ牛で気付かせる |
| 予告 | 45 | 路面の光を見て進路を選ぶ |
| 照射 | 60 | 光線と反対側を通り抜ける |
| 退場 | 30 | 通常のドライブへ戻る |

30fpsなら全体で約5.5秒です。光線は片側に出現し、反対側に逃げ道を残します。捕まった自車は短く浮き、減速して道路へ戻ります。一周に一度だけ出現し、次の周回では左右を入れ替えます。新しい操作キーは不要です。

### 自分の記録を更新する

`TIME`と`BEST`を0.1秒単位で表示します。周回完了で記録し、そのまま次の計測を始めます。停車や接触からの復帰時間も含め、Escによるポーズ中は除外します。

時間切れ・燃料切れ・強制ゲームオーバーはありません。最速と直前の周回時間はRAM内に保持し、リセット・終了で消えます。直前の記録は内部保持のみで、現行HUDの表示はTIMEとBESTです。

## 512KiBで積み上げる

対象はMSX turbo RのR800モードとV9990です。V9990のB1モード、256×212画素・16色で描画します。

道路は1024地点分の投影座標から描き、坂による遮蔽も計算済みデータから適用します。一般車も同じ道路の投影と遮蔽を使います。ゲーム進行や操舵、描画、音はROM内のプログラムで実行します。

| ASCII8バンク | 内容 |
| --- | --- |
| 0 | 起動処理 |
| 1～3 | RAMへ転送する実行コード |
| 4～11 | 基本画像・車・イベント・文字 |
| 12～43 | コースと投影データ |
| 44～59 | 巨木・断崖の追加画像 |
| 60～63 | 予備領域 |

配置済みは480KiB、予備は32KiB。ROM全体は524,288バイトです。コース転送、描画順、文字キャッシュなどを工夫し、見た目と操作の反応を両立させます。

## 今後の候補

落石、ジャンプ、路面の変化、長距離コース、分岐、ライバル車などを検討しています。v0.4には未実装です。まずは現在の追い越しとUFO遭遇の感触を確かめ、予告・逃げ道・短い復帰を保ちながら積み上げます。
